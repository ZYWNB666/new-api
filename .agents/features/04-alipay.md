# 04 · 支付宝支付

- **状态**：活跃
- **引入提交**：`9c727251b`（后端）、`6288aec2f`（前端弹窗与 i18n）
- **影响面**：充值链路、钱包前端

## 功能说明

在既有支付方式之外新增支付宝充值，含前端支付弹窗与本地化字符串。

## 实现要点

- 后端 `controller/alipay.go`：下单、回调验签、状态查询。
- `setting/payment_setting` 增加支付宝配置项（app id、私钥、公钥、回调地址）。
- 前端 `web/src/features/wallet/`：`lib/payment.ts`、`lib/ui.tsx`、`types.ts` 增加支付宝分支与弹窗组件。
- i18n：7 语言同步新增支付相关字符串（`zh.json`、`zh-TW.json` 各 +20/+9）。

## 配置与开关

管理后台支付设置中填写支付宝参数后生效。回调地址需与配置一致。
