## 一、我们处理的信息

### 1. 账号与身份信息

注册及维护账号时，我们可能处理用户名、电子邮箱、密码摘要、账号状态、用户编号及您主动填写的资料。我们不保存可还原的明文密码。

使用 GitHub、LinuxDO、Google、微信或其他第三方登录时，我们按照授权页面所示范围接收必要的第三方账号标识、用户名、头像、电子邮箱或授权结果。我们不会因第三方登录而自动取得超出授权范围的信息。

### 2. 登录、安全与设备信息

为保障账号和系统安全，我们可能处理登录时间、IP 地址、设备及浏览器基本信息、会话标识、OAuth 状态记录、验证结果、异常行为和安全审计事件。会话 Cookie 用于维持登录、安全防护和必要偏好，不用于与服务无关的跨站广告追踪。

### 3. API Key 与调用元数据

API Key 原则上仅在创建时完整展示，之后保存不可逆摘要、必要的加密材料或掩码信息，用于鉴权和管理。

我们不持久化保存请求正文、上传内容和模型响应正文。为完成路由、计费、故障排查、安全审计和账单查询，我们会记录必要的调用元数据，包括：

- 请求时间、请求编号及账号或 Token 标识；
- 所选模型、实际供应商或路由类别；
- 输入/输出 Token 数量或其他计量单位；
- 费用、余额变化、响应耗时、状态码及错误类型；
- 为识别攻击、滥用和计费争议所必需的网络及安全信息。

“不持久化保存正文”是指平台应用不会主动将正文写入数据库、业务日志或文件存储。请求和响应仍需在内存及网络链路中进行瞬时处理，基础设施可能产生不包含正文的必要技术记录。依法必须处置安全事件时，我们仅在必要范围内采取措施。

### 4. 充值、退款与交易信息

充值或退款时，我们可能处理订单号、金额、币种、支付渠道、支付状态、时间、退款原因以及支付机构返回的必要交易标识。完整银行卡号、支付密码等信息通常由持牌支付机构处理，我们不主动收集。

为防止欺诈或处理退款，我们可能要求您提供与订单相关的必要核验材料。与目的无关的信息请主动遮挡。

### 5. 客服与权利请求信息

您联系我们、提交投诉、退款或个人信息权利请求时，我们会处理邮件地址、问题内容、沟通记录及核验身份所需的信息。

## 二、处理目的与依据

我们在下列必要范围内处理信息：

1. 创建和维护账号，提供登录、鉴权、API 转发、计量、账单和退款服务；
2. 履行与您的服务合同及法定义务；
3. 保障账号、支付、网络及平台安全，识别欺诈、攻击、密钥泄露和违规使用；
4. 处理客服、投诉、纠纷、审计及监管要求；
5. 经您同意处理可选信息，或在法律规定的其他合法基础上处理信息。

我们不会通过一次概括授权强制您同意与服务无直接关系的信息处理，也不会将必要信息用于无关目的。处理目的、方式或个人信息种类发生实质变化时，我们将依法告知并在需要时重新取得同意。

## 三、请求内容的实时转发

1. 当您选择某个模型并发起调用时，我们仅为完成该次服务，将请求正文、上传内容及必要技术参数实时传输给对应供应商，并将响应返回给您。
2. 上述内容可能包含您主动输入的信息。您应在提交前完成脱敏，并确保具备合法处理依据及向供应商提供该信息的权利。
3. 本平台不以请求或响应正文训练自有模型，也不将其用于广告画像。
4. 供应商是否留存、用于安全审查或改进服务，取决于实际产品、账号类型、区域配置及供应商条款。我们不对供应商作出未经其书面承诺的固定留存保证。

## 五、跨境处理

选择 OpenAI、Anthropic、Google 等境外或全球处理的模型时，请求内容及必要技术数据可能被传输至中国境外。我们将在相关功能启用或首次调用前提供显著告知并依法取得单独同意，同时履行适用的数据出境合规义务。

如果您不同意境外处理，请勿选择相关模型，可选择平台实际提供的境内处理模型。不得通过本平台传输法律法规禁止出境的数据、重要数据，或者未经授权的个人信息及敏感个人信息。

## 六、敏感个人信息

本平台不要求您在模型请求中提交敏感个人信息。如果确需处理生物识别、医疗健康、金融账户、行踪轨迹、特定身份或未满十四周岁未成年人的信息，您应先取得充分合法授权并完成必要评估；平台将在自身依法处理敏感个人信息时说明必要性和对个人权益的影响，并取得单独同意。无法满足要求时，请勿提交。

## 七、保存期限

我们遵循实现目的所必要的最短期限：

1. 请求和响应正文：平台不持久化保存，仅在完成转发和返回响应所需期间瞬时处理；
2. 调用及计费元数据：一般保存不少于180日，并根据账单查询、安全审计、争议处理及法定义务确定最终期限；
3. 登录、安全和审计记录：一般保存180日；发生安全事件、投诉或争议的，可保存至事件处理完毕及法定追责期限届满；
4. 账号资料：在账号存续期间保存，注销后原则上于30日内删除或匿名化，但法律要求保留或争议尚未处理完毕的除外；
5. 充值、退款、发票及交易记录：按照会计、税务、支付、反洗钱及消费者权益保护等适用法律规定的期限保存；
6. 客服及权利请求记录：保存至请求处理完成后的合理审计期限。

超过期限后，我们将删除或匿名化处理。因法律规定或技术上难以立即删除的，我们将停止除存储和必要安全保护之外的处理。

## 八、信息共享、委托处理与公开

除实时转发给您选择的供应商外，我们仅在以下情形共享或委托处理信息：

1. 为完成支付、邮件、云基础设施、安全防护和客户支持所必需；
2. 经您单独同意向其他个人信息处理者提供；
3. 根据法律法规、司法或行政机关依法提出的要求；
4. 为保护您、我们或公众的生命健康、财产与网络安全，在法律允许范围内采取必要措施。

我们会通过合同等方式约束受托方的目的、期限、方式、信息种类和保护措施，并进行合理监督。未经合法依据，我们不会出售个人信息，也不会公开您的个人信息。

## 九、安全保护

我们采取访问控制、传输加密、凭证摘要或掩码、权限隔离、日志审计、备份和安全事件处置等合理措施。互联网服务无法保证绝对安全；发生或可能发生个人信息泄露、篡改、丢失时，我们将依法采取补救措施，并在法律要求时通知受影响个人和主管部门。

您也应使用强密码、妥善保存 API Key、限制密钥权限并在发现异常时立即撤销。
